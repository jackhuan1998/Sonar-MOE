## Overview

- **`fre_domain.py`** contains `DCTMultiSpectralAttention`, `LargeKernelSpatialAttention`, `LocalDetailAttention`, and other expert modules.

- **`budget_expert_search.py`** implements the **Resource-Constrained Stage-Wise Expert Screening Strategy (RC-SES)**.

- **`routers.py`** implements the routing mechanism with configurable **`pool_size`** and **`temperature`**.

- **The remaining components will be released upon publication of the paper.**
